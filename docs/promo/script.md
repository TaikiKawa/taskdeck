# TaskDeck 社内プロモ動画 — 台本 + 絵コンテ

- 目的: Alche 社内（エンジニア・非エンジニア問わず、Claude Code / Claude Desktop を少しは触ったことがある人）に TaskDeck を「使ってみたい」と思ってもらう
- 尺: 目標 2:30 / 上限 3:00
- 言語: 日本語ナレーション（TTS でも人が読んでも可）
- 関連: 撮影手順は `docs/promo/shotlist.md`

---

## 動画のコンセプト

**「覚えておく係を、Claude と TaskDeck にまかせる」**

売りたいのは機能の数ではなく、「頭の中の『やらなきゃリスト』が消える」体験。
だから前半は「Claude が勝手に積む」→「ポチッと渡す」→「進捗も勝手に動く」の 3 つを、実際の画面が勝手に動く瞬間で見せる。
仕組み（MCP、SQLite、SSE）は最小限しか語らない。「ローカルで完結」「Mac / Windows 両対応」だけ一言添える。

視聴後に残したい一文:
「タスクを覚えておくのはもうやめて、Claude に積んでもらって、ポチッと渡せばいい」

## トーン

- 社内向け。同僚が隣で「ちょっとこれ見て」と見せてくれる温度感
- 敬語だけど硬くない。営業資料の言い回し（「革新的」「シームレス」等）は使わない
- ちょっと遊び心（「そして、忘れます。」みたいな間）
- テロップは短く、画面の実際の文言をそのまま使う。BGM は軽めのローファイ / チル系で、ナレーションを邪魔しない音量

## ナレーション全文（読み上げ用、区切りは空行）

これやらなくちゃ、あれもやらなくちゃ。作業してると、頭の中のやることリストがどんどん増えますよね。しかも、だいたい忘れます。

TaskDeck は、自分の Mac や Windows の中だけで動く、シンプルなカンバンです。Todo、Doing、Done の3列。ここまでは普通。違うのは、このボードを Claude も見ているところ。MCP でつながっていて、人間も Claude も、同じ板を見て動かします。

たとえば、Claude Code で作業中。会話の流れで「ここ、直したほうがいいね」って話になったとします。今までなら、頭の片隅にメモして、忘れる。でも TaskDeck があると、Claude がその場で task_add を呼んで、ボードにカードが増えます。ブラウザは触っていません。勝手に出てきます。「直したほうがいいところ、積んでおいて」と頼めば、まとめてドンと積んでくれます。頭の中に置いておかなくていい。ここが一番うれしいところ。

積まれたタスクは、カードのロボットのボタンをポチッと押せば、Claude に渡せます。作業フォルダは、Claude が登録したタスクなら自動で入っています。実行先は、デスクトップアプリで開くか、バックグラウンドでおまかせするか。権限は「安全」か「全自動」を選んで、実行。カードに「実行中」のバッジが付いて、あとは待つだけです。

進捗も、自分で動かさなくて大丈夫。Claude が着手すると Doing に、終わると Done に、カードが勝手に移動します。完了すると、実行ログがメモに残ります。カードには番号が付いているので、「#12 のタスクやって」の一言で頼めます。

セットアップは 10 分くらい。Mac でも Windows でも動きます。コマンド一発、npm run mcp:register。これで Claude Code からボードが見えるようになります。

タスクを覚えておくのは、もう Claude と TaskDeck にまかせて。私たちは、考えるほうに集中しましょう。セットアップガイドは docs/SETUP.md、質問は Slack の #taskdeck へ。ぜひ試してみてください。
