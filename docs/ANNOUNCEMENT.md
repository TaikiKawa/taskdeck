## 長い版（15行程度）

```
【ゆるく共有】TaskDeck っていうカンバン、チームで使えるようにしました 🗂️

もともと自分の「あれやらなきゃ」を Claude と共有するために作った、完全ローカルのミニマルなカンバンです。
Todo / Doing / Done の3列だけ。クラウドには何も送りません。

■ 何がうれしいか
・Claude に「今日やること3つ登録して」と言うと、ボードにカードが勝手に出てくる
・Claude Code で作業中に「これ後でやった方がいいな」と気づいたことも、Claude 自身がボードに残していく
・カードの 🤖 ボタン1つで、そのタスクを Claude に丸投げできる
　（Claude デスクトップアプリに新規セッションとして開く / claude CLI でバックグラウンド実行、が選べる）
・Claude が着手すると Doing、終わると Done にカードが勝手に動いて、実行ログもカードに残る

■ 使うには
・Mac / Windows 両対応。Node.js と git があればセットアップは10分くらい
・Claude Code CLI か Claude デスクトップアプリのどちらかがあれば OK（Codex CLI でも使えます）
・1人1ボードで、同僚と自動同期されるものではないです（自分の頭の整理用）

🎥 1分でわかる動画: {{VIDEO_URL}}
📖 セットアップガイド（初めての人向け・手順コピペで OK）: {{SETUP_URL}}

使う・使わないは完全に自由です。「入れてみたけど動かない」「こういうのできる？」はこのスレにどうぞ 🙌
```

## 投稿時のメモ

- 動画は「Claude に話しかける → カードが出る → 🤖 → Doing → Done」の流れが 1 分で見えると一番伝わります
- 非エンジニアには「Claude デスクトップアプリで開く」ルートだけで十分使えるので、CLI の話は深掘りしなくて OK
- 質問はスレッドに集めると、同じ質問への回答がガイドに反映しやすいです
